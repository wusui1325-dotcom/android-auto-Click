# android-auto-Click

最簡潔、好看、免廣告的自動點擊 / 連點器 Android App。

## 目標

- **極簡畫面**：乾淨、現代、無多餘元素
- **好看設計**：流暢動畫、舒適配色、直覺操作
- **完全免廣告**：無任何廣告、無內購干擾
- **最佳體驗**：穩定、精準、低耗電、高自訂性

## 功能規劃

- 單點 / 多點點擊
- 連點（固定間隔或隨機）
- 錄製點擊序列
- 浮動懸浮窗操作
- 手勢與快捷鍵支援
- 深色 / 淺色主題自動切換

## 目前狀態

✅ 連點引擎（間隔／次數／多點／單次測試）  
✅ 懸浮窗（可拖曳，顯示剩餘與當前點）  
✅ 序列錄製、儲存、回放、等待步驟  
✅ 點擊記錄  
✅ 平面 iOS Settings 風格介面  

## 下一步

- 從無障礙事件自動錄製座標
- 序列編輯（刪除／排序步驟）
- 浮動面板更多控制




- 簡潔優先
- 效能與穩定性第一
- 開源、透明、無追蹤
