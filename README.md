# android-auto-Click

最簡潔、好看、免廣告的自動點擊 / 連點器 Android App。

## 目標

- **極簡畫面**：乾淨、現代、無多餘元素
- **好看設計**：流暢動畫、舒適配色、直覺操作
- **完全免廣告**：無任何廣告、無內購干擾
- **最佳體驗**：穩定、精準、低耗電、高自訂性

## 功能規劃

- 單點 / 多點點擊
- 連點（固定間隔或隨機）
- 錄製點擊序列
- 浮動懸浮窗操作
- 手勢與快捷鍵支援
- 深色 / 淺色主題自動切換

## 目前狀態

✅ 連點引擎（單點／多點／隨機／防偵測／開始延遲／暫停／CPS 上限／最長時間）  
✅ 懸浮窗（可拖曳，單擊／雙擊／長按，顯示剩餘、當前點、暫停、座標）  
✅ 序列：自動錄製、滑動、等待、儲存、回放、循環、匯出／匯入、複製  
✅ 設定持久化與匯出／匯入、執行通知、點擊記錄、總點擊  
✅ 震動、音效、保持螢幕、快速預設、主題切換  
✅ 平面 iOS Settings 風格介面
