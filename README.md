# android-auto-Click

最簡潔、好看、免廣告的自動點擊 / 連點器 Android App。

## 目標

- **極簡畫面**：乾淨、現代、無多餘元素
- **好看設計**：流暢動畫、舒適配色、直覺操作
- **完全免廣告**：無任何廣告、無內購干擾
- **最佳體驗**：穩定、精準、低耗電、高自訂性

## 功能規劃

- 單點 / 多點點擊
- 連點（固定間隔或隨機）
- 錄製點擊序列
- 浮動懸浮窗操作
- 手勢與快捷鍵支援
- 深色 / 淺色主題自動切換

## 目前狀態

✅ 專案殼（Kotlin + Jetpack Compose）  
✅ 無障礙服務 + 手勢點擊  
✅ 懸浮窗（可拖曳，開始／停止）  
✅ 點擊參數即時連動 ClickController  
✅ 序列錄製骨架  
✅ 平面 iOS Settings 風格介面  

## 下一步

- 座標點擊錄製（從無障礙事件）
- 序列回放
- 浮動面板顯示剩餘次數



- 簡潔優先
- 效能與穩定性第一
